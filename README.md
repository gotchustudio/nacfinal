# Neat & Clean Laundry

The public website starts at [`index.html`](./index.html). Its styles and scripts are embedded in the page; the hero image, [`1laundry.jpg`](./1laundry.jpg), is in the repository root.

The site is a static brochure website for exploring services, pricing, reviews, and Kathmandu service areas, then contacting the business by phone, email, or WhatsApp.

## Publish

Publish the repository root with GitHub Pages or another static host. The site and its local assets use relative paths, so it works at the repository URL and when `index.html` is opened directly.
